# Ashmit Dev's Interactive Portfolio

🔗 **Live Demo**: [https://devashmit.github.io/Dev-s-Portfolio/](https://devashmit.github.io/Dev-s-Portfolio/)

A premium, highly interactive developer portfolio built with React, Vite, and cutting-edge web design aesthetics. Featuring custom physical interactions, a custom cursor, retro IDE controls, and a playful canvas-based AI companion.

## 🛠️ Technology Stack

- **Framework**: [React 19](https://react.dev) + [Vite](https://vite.dev) (lightning-fast modular HMR)
- **Styling**: Vanilla CSS (maximum customizability)
- **Animations**:
  - [Framer Motion](https://www.framer.com/motion/) (smooth state transitions, custom spring-tuned spotlights)
  - [GSAP](https://gsap.com/) + ScrollTrigger (optimized scroll reveals)
- **Smooth Scrolling**: [Lenis](https://lenis.darkroom.engineering/) (60fps smooth scrolling, optimized to auto-disable on mobile)

## ✨ Premium Features

- **Interactive Canvas Console**: Play a custom-styled retro Snake game with custom speed levels and sound effects directly from the interactive IDE terminal component.
- **Cat Companion AI**: An interactive, screen-chasing pet cat that pursues summonable toys, avoids interactive game canvases to prevent overlap, and celebrates catches with dynamic sounds and hop animations.
- **Custom Cursor & Spotlight**: A spring-tuned spotlight tracker that expands when hovering over interactive UI/UX components.
- **Theme Transitions**: A gorgeous radial sweep animation transitioning between Dark and Light mode.
- **Performance Optimized**: Custom layout caching and event-driven invalidation to avoid browser layout thrashing and maintain constant 60fps performance.

## 🚀 Getting Started

### Installation

```bash
npm install
```

### Run Locally

```bash
npm run dev
```

### Production Build

```bash
npm run build
```
